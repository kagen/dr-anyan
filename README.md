# Dr Anyan (Dr. Mario-like)

An Android Dr. Mario-like puzzle game.

## Features
- 8x16 board
- Falling two-color capsules
- Clear 3+ same-color cells in rows/columns
- Gravity after clears
- Chain flash effect + chain text
- SFX/BGM and level-based speed scaling
- Level clear celebration and auto advance to next stage
- Pause/Resume/New Game anytime

## Controls
- Swipe left: move left
- Swipe right: move right
- Tap: rotate clockwise
- Swipe down: hard drop
- Long press left area: continuous left move
- Long press right area: continuous right move

## Build
```bash
./gradlew assembleDebug
```

APK:
`app/build/outputs/apk/debug/app-debug.apk`
